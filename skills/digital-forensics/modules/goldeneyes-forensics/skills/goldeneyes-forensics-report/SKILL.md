# 火眼取证报告草拟

## 使用前提

本 skill 只能整理已获授权、已经分析并完成人工复核的材料，不能自行搜索、读取、复制或补采证据。草拟规则全部写在本文件，不需要读取其他细则文件。

## 报告章节

按以下顺序输出，章节不得缺省：

1. 任务范围与委托事项
2. 案件与检材：逐项写编号、完整路径、来源、授权范围、时间范围、解析状态
3. 方法与实际执行命令
4. 事实发现
5. 分析推断
6. 待核验事项
7. 局限性与未覆盖范围
8. 结论与建议下一步

## 草拟规则

1. 缺失信息明确写“未提供”或“待核验”，不得自行补造。
2. 原样保留输入中的真实 Goldeneyes:// 角标，使每个角标紧随其支持的事实；不得改写、合并、猜测、新造或用路径、`cid`、旧句柄替代。
3. 将内容明确区分为“事实”“分析推断”“待核验事项”，不得用推断替代事实。
4. 每项结论写明依据、结论强度和局限性；存在矛盾材料时并列呈现，不擅自取舍。
5. 区分 GES 解析记录与原始检材；语义分数、关键词命中、复制文件或不完整结果不得直接写成事实。
6. 若事实缺少原始依据、有效角标或必要上下文，停止形成肯定结论并列为待核验事项，明确退回 ges-case-analysis 补充检索、`read` 回查与交叉验证；补查完成前不得继续补写。
7. 记录实际使用的工具/skill 版本、执行命令、成功码，以及失败或未执行步骤；token 和其他认证信息必须脱敏且不得写入。
8. 输出始终标注为真人审签前的报告草稿。
