# 四类取证笔录要素与模板

本文件提供通用草稿结构，不替代部署单位制式文书。只保留实际发生和能够确认的章节；单位模板已提供时，按其字段顺序映射以下要素。

## 一、共同要素

- 案件或任务标识、案件类型、取证目的和授权范围。
- 作业人员及角色、其他在场人员、开始与结束时间、地点。
- 取证对象及唯一标识：设备、介质、系统、账号、网络地址、数据源或检材编号。
- 作业前状态、环境和必要的保护措施。
- 工具、软件或设备名称与实际显示的版本信息。
- 按时间顺序记录的实际操作、执行状态和异常情况。
- 取得、生成或发现的数据及其来源、数量、格式、保存位置和完整性校验信息。
- 照片、截图、录屏、日志、提取固定清单、封存或移交材料等附件。
- 补充、更正、确认、签名或拒签等信息，只能按真实材料记录。

## 二、现场勘验模式

适用于在现场对电子设备、信息系统或网络环境进行勘验并记录电子数据相关过程。重点收集：

- 现场位置、区域范围、进入现场后的设备和网络状态。
- 设备摆放、开关机、登录、连接、外设和运行界面等原始状态。
- 拍照、录像、屏幕固定、网络隔离、电源保护等实际采取的措施。
- 发现的电子设备、存储介质、账号、应用、数据界面及编号对应关系。
- 现场执行的查看、固定、提取或封存操作及其结果。
- 作业结束时设备、介质、现场和数据的处置状态。

通用正文骨架：

```text
一、任务与现场
〔案件或任务〕〔勘验地点〕〔人员〕〔起止时间〕〔勘验范围〕

二、现场及电子设备原始状态
〔设备、介质、网络、界面、连接和编号〕

三、勘验过程
〔按时间顺序记录实际动作、工具方法、保护措施和异常〕

四、勘验结果及数据固定
〔发现或固定的数据、保存位置、数量、校验值和对应附件〕

五、结束状态与附件
〔设备或现场处置、封存移交、照片截图录屏和清单〕
```

## 三、远程勘验模式

适用于在明确授权范围内通过网络对远程信息系统、网络空间或在线数据进行勘验。重点收集：

- 远程目标的名称、地址、账号或其他定位信息，以及这些信息的来源。
- 勘验端设备、网络环境、工具名称和版本、系统时间及时区。
- 访问开始与结束时间、访问方式和实际使用的授权身份；正文不记录密码、令牌或密钥原值。
- 页面、接口、目录、会话或数据对象的访问顺序和操作步骤。
- 截图、录屏、网络或工具日志与具体步骤的编号对应关系。
- 下载、导出或固定的数据来源、路径、格式、数量、保存位置和校验值。
- 访问失败、中断、重连、内容变化、权限限制和无法复现情况。

通用正文骨架：

```text
一、任务、目标与授权范围
〔远程目标〕〔定位信息来源〕〔作业人员〕〔起止时间〕

二、勘验环境
〔勘验端设备、网络、工具版本、系统时间及时区〕

三、远程勘验过程
〔按时间顺序记录访问对象、实际操作、截图或录屏编号及异常〕

四、数据固定与校验
〔数据来源、导出或下载方式、保存位置、数量和实际校验值〕

五、结束状态与附件
〔会话结束、未完成事项、日志、截图、录屏和清单〕
```

## 四、电子数据提取模式

适用于从设备、介质、系统、账号或在线数据源中提取电子数据。现行单位模板可能进一步区分现场提取、网络在线提取等情形。重点收集：

- 提取对象、持有人或管理人、原始位置、设备或介质状态和唯一标识。
- 提取原因、范围、数据类别、时间范围和目标；是否存在不能扣押原始介质等需要说明的情形，以用户材料为准。
- 提取人员、在场人员、地点、起止时间和工具版本。
- 原始数据访问路径、提取方法、筛选条件和实际操作步骤。
- 输出数据的目录或载体、文件或记录数量、格式、大小及失败项。
- 实际执行的完整性校验算法和校验值；原始对象、提取结果和封存载体的校验值不得混写。
- 输出载体编号、封存、交接和附件对应关系。

通用正文骨架：

```text
一、提取任务与对象
〔任务〕〔对象及标识〕〔数据范围〕〔人员地点时间〕

二、提取前状态与环境
〔介质或系统状态、工具版本、访问条件、保护措施〕

三、提取过程
〔来源路径、筛选条件、按时间顺序记录的实际操作和异常〕

四、提取结果与完整性校验
〔输出位置或载体、数据类别、数量、大小、算法、校验值、失败项〕

五、封存移交与附件
〔载体编号、封存或交接状态、日志、截图、录屏和提取固定清单〕
```

## 五、电子数据检查模式

适用于对已经依法取得或提供的电子数据、镜像、介质或副本开展检查。重点收集：

- 检查对象的来源、检材编号、交接信息、封存状态和作业前校验值。
- 检查目的、范围、关键词、时间范围或数据类别；只记录真实任务条件。
- 检查环境、写保护或副本使用情况、工具名称和版本。
- 解封、接收、挂载、加载、解析、检索、查看、恢复、导出等实际执行的步骤。
- 工具任务状态、解析范围、错误、跳过项、部分结果和人工复核情况。
- 客观发现、来源路径或记录位置、导出结果和校验值；分析推断与观察事实分开。
- 检查结束后的数据保存、载体状态、重新封存、交接和附件。

通用正文骨架：

```text
一、检查任务与检材
〔检查目的〕〔检材来源和编号〕〔人员地点时间〕

二、检查前状态与环境
〔封存或交接状态、校验值、写保护或副本、工具版本〕

三、检查过程
〔按时间顺序记录加载、解析、检索、查看、恢复或导出操作〕

四、客观检查结果
〔实际发现、来源位置、导出数据、任务状态、限制和校验值〕

五、结束状态与附件
〔数据保存、载体处置、重新封存或交接、日志和清单〕
```

## 六、多模式作业

现场勘验中实施数据提取、提取后又开展检查时，先按单位要求判断是同一笔录分段记录还是分别成文。无明确规则时，分别生成草稿并建立交叉引用，避免把不同时间、对象、工具结果和责任人员混写。
