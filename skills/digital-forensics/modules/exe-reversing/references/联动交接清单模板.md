# 联动交接清单模板

> 静态（IDA）与动态（x64dbg）共享同一份清单，会话内维护，两端按本模板字段读写。
> 若桌面端已装 ret-sync 等 IDA↔x64dbg 实时同步插件，先核实连接及地址/符号同步结果，再省去已完成的手工搬运。
>
> **地址对齐（ASLR/重定位）**：先核对目标文件、模块身份与架构，分别记录 IDA image base 和 x64dbg 运行时模块加载基址。相同模块布局下，`RVA = IDA 地址 − IDA image base`，`运行时地址 = 运行时模块加载基址 + RVA`；反向换算使用 `RVA = 运行时地址 − 运行时模块加载基址`。
> 静态端用 `make_signature_for_function` 生成字节签名；动态端先确认运行时 `FindPattern` 的参数与扫描范围，再搜索并用字节、反汇编及模块范围核对候选。无匹配或多匹配时保留待定位状态，不直接选第一项；解包、自修改或布局改变时重新建立映射，不套用旧 RVA。
> 以下表格仅保留字段，按本案真实证据添加数据行；没有数据时说明缺口，不把字段说明当作发现。

字段说明：每个地址对应已核实的同一模块和布局；语义名来自实际分析命名，签名记录实际生成内容及候选核对结果；未确认字段标为待确认。

| 目标地址 | 建议动作 | 建议名称/注释 |

字段说明：目标地址换算到当前 IDA 数据库；动作可为重命名、添加注释或定义数据，执行时使用静态技能中经运行时确认的工具；名称和注释只反映已取得的证据。

## 状态流转
待验证 → 已验证（证实/证伪）/ 存疑（写明下一步）→ 回填后再验证或完成。有证据缺口但无法继续时记录阻塞原因与人工复核路径，保留未验证状态。
