# 常见反调试与混淆应对清单

## 反调试
- `IsDebuggerPresent` / `CheckRemoteDebuggerPresent` → 置零返回值或补丁跳转
- `NtQueryInformationProcess`(ProcessDebugPort / ProcessDebugObjectHandle) → 观察并补丁
- PEB.BeingDebugged / NtGlobalFlag → 调试会话内改内存
- `rdtsc` / `GetTickCount` / `QueryPerformanceCounter` 时间差 → 记录触发点
- `int 2d` / `int 3` 异常反调试 → 调整异常处理策略
- 硬件断点探测（读取 DR0–DR7）→ 改用软件断点或内存断点

## 混淆
- 花指令 / 垃圾代码 → 记录，不强解，重点放交叉引用与数据流
- 导入表动态解析（`GetProcAddress` 运行期取址）→ 动态阶段下断点抓真实地址
- 字符串/代码自解密（`VirtualAlloc` + 写 + 执行）→ dump 解密后内存再静态分析

## 原则
- 绕过手段与改动必须记录，报告里注明「在调试会话内施加，未改原样本」。
