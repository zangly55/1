# 专家证据模型

产品 Skill 的公开结果是事实来源。专家不重新定义产品执行结果，不要求产品 Skill 知道专家状态，也不生成授权、任务或原始响应引用。

## 专家证据记录

专家只为跨 Skill 审查建立证据索引：

```text
evidence_id          当前问题内的专家证据标识
source_result_ref    Skill 返回的结果、证据、源码或产物引用
facts                从来源结果直接提取的事实
interpretation       只解释 facts，不引入新事实
evidence_level       E1 / E2 / E3 / E4
boundaries           截断、未覆盖、不可见、混淆、加固、交互范围
conflicts            与其他证据的冲突及双方 evidence_id
conclusion_strength  confirmed / supported / suspected / not_observed / unknown / contradicted
```

产品结果中的 `cid/aid/tid`、授权信息、执行状态和原始响应引用仅作为来源元数据原样引用，不是专家生成或校验的字段。缺少持久化引用时明确“仅当前会话可复核”，不得虚构存储位置。

一个 Skill 结果可以支持多条专家证据；多页、启动、停止和状态查询如何聚合由产品 Skill 或运行时决定。专家只消费公开结果，不读取未治理的原始输出。E4 由专家审查生成，必须引用至少一个 E2 和一个 E3 来源。
