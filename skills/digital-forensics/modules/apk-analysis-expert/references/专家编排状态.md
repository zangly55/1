# 专家编排状态

```text
planned -> evidence_requested -> awaiting_result -> reviewing -> completed
```

- `planned`：已固定问题和 APK 范围，正在识别证据缺口。
- `evidence_requested`：已选择下一产品 Skill，并提交分析目标和必要作用域。
- `awaiting_result`：产品 Skill 正在处理、等待用户交互或受控操作决定。
- `reviewing`：已收到公开结果，正在审查事实、边界、冲突和结论强度。
- `completed`：问题已回答，或所有剩余缺口均有明确阻塞、不可用或人工复核结论。

环境或执行条件不满足进入 `blocked`；证据冲突且无法自动裁决进入 `needs_manual_review`。产品 Skill 的授权状态、任务状态、任务 ID、分页位置和清理动作保持原样，不映射为专家自己的执行状态。

Skill 返回任务仍运行或结果尚未完整时，专家可以继续请求该 Skill 补充结果，也可以阶段性交付；阶段性结论必须标为 `partial`，并说明来源结果报告的运行状态、完整性边界和后续条件。
