# 应用分析研判报告模板

本文件定义报告内容和章节结构，不是最终报告文件。用户未指定格式时，报告 Skill 应根据本模板生成一个自包含 HTML 文件。

## HTML 生成要求

- 使用 UTF-8 编码和完整的 `<!doctype html>` 文档结构。
- CSS 全部内联，不引用外部样式、脚本、字体或图片。
- 页面适配桌面浏览和打印；宽表格允许横向滚动，打印时避免标题与对应内容分离。
- 应用信息等双列表格使用稳定列宽：首列建议 `min-width: 110px; width: 18%`，不得因窄视口压缩到逐字换行；表头和项目名称允许按词自然换行。
- 长文件路径、哈希和命令使用 `overflow-wrap:anywhere` 或等效规则断行；不得撑破页面或遮挡其他内容。
- 最终文件中不得保留占位符、模板说明或没有实际内容的章节。
- 使用语义化标题、表格、列表和结论块，不把 Markdown 源文直接包进 HTML。

## 报告标题

`{{应用名称}}应用分析研判报告`

标题下显示报告生成时间，并声明报告用于技术研判和人工复核，不替代合规、法律或责任认定。正文不显示案件、证据和任务的内部 ID（如 cid、aid、tid、evidence_id）；如确需追溯，使用受控审计附录。

## 八、重点发现与影响

- 标题

- 已经审查的结论
