# 资金流水分析报告草拟

## 输入前提

输入必须已经完成证据审查，至少包含：用户问题、分析范围、数据时间范围、账户与人员信息、WMX 解析数据虚拟路径、战法命中结果、结论强度、冲突、边界、未回答问题，以及实际执行命令的状态。缺少关键来源或结论尚未定级时停止草拟，并返回待补充项。

草拟前读取 [资金流水分析报告模板](../../references/资金流水分析报告模板.md)。输入中的结论强度、审查结果和证据定位视为调用方已经确定的约束，不在本 Skill 中重新裁决。

## 边界

- 不调用 WMX CLI，不创建、查询或停止解析任务，不导入检材。
- 不读取未治理的原始 CLI 输出，不补造缺失的虚拟路径、交易 ID、任务 ID 或产物。
- 不修改专家给出的结论强度、统计口径和冲突裁决。
- 输入证据不足时使用“未提供”“待验证”或“数据不足，无法判断”，不将计划写成已执行。
- 不将战法命中、交易频率或资金路径直接等同于违法违规事实认定。

## 草拟规则

1. 按模板组织案件信息、分析范围与统计口径、案件分析摘要、人员与账户、资金分析、跨人员与跨账户综合分析、综合研判、结论限制、证据索引和附录。
2. 将“数据事实”“规则命中”“分析判断”“待核查线索”和“局限性”明确区分；关键结论附 WMX 虚拟路径、交易 ID、行号或记录位置作为证据定位。
3. 金额注明币种和统计口径，时间注明时区与范围，比例注明分母；对同一账户内部转账、冲正、退款和重复记录说明是否去重。
4. 按模板的执行状态规则处理空结果：已成功执行且结果完整但未命中时保留标题与未命中说明；未执行、失败、仍在运行或结果不完整时如实披露，不写成未命中或确认无异常。
5. 如实披露解析失败、字段缺失、样本偏差、时间范围不足、仍在运行的任务和统计口径限制。
6. 排名表默认展示前 10 项；不足 10 项时展示全部。大量明细放入附录或独立文件，正文只展示代表性内容。
7. 简单问题不强制生成完整报告；调用方明确要求综合报告时按模板输出完整报告。

## 输出

用户未指定报告格式时，输出 Markdown 报告；用户明确要求 HTML、Word 或其他格式时按需求输出。报告只能复述和组织输入中已经审查的事实与结论，不能替代专家的分析审查或最终定级。
