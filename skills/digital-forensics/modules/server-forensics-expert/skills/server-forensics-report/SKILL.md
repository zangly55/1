# 服务器取证报告草拟

## 使用前提

这个 skill 只整理已经核查过的证据，不做新的采集、仿真启动或格式转换。草拟前先读：

- [取证报告模板](../../references/取证报告模板.md)
- [结论强度与术语规范](../../references/结论强度与术语规范.md)
- [人工复核清单](../../references/人工复核清单.md)

## 草拟规则

1. 只写已确认的事实、可核查的推断和明确标出的待复核项。
2. 保留真实路径、日志名称、配置片段、时间戳和仿真记录，不改写来源。
3. 把事实、分析、限制和建议分开写，不把推断写成既成事实。
4. 证据不足时明确写“未提供”或“待复核”，不要自行补全。
5. 不负责调用 `create-vm`、`clonezilla-to-e01` 或其他采集型 skill。

## 输出

默认输出 Markdown 报告草稿；如果用户指定 HTML、Word 风格结构或其他格式，就按模板内容重排，但仍保持证据、分析和限制分离。
