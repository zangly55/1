# 仿真技能使用规则

服务器取证里，仿真只服务于证据核查，不替代证据本身。

## 先后顺序

1. Clonezilla 备份目录先用 `clonezilla-to-e01` 转成 E01。
2. 需要把磁盘镜像启动起来看系统状态时，用 `create-vm`。
3. 需要查看虚拟机地址时，再用 `create-vm` 提供的 `get-ip` 能力。

## 使用原则

- 只在副本或派生路径上操作，原始检材保持只读。
- 仿真结果必须回到日志、配置、文件和时间线做交叉验证。
- 如果用户只想做离线日志分析或报告整理，不主动启动仿真。
- 遇到不支持的镜像格式，先说明限制，再给出可转换路径。

## 常见输入

- `create-vm` 适合 `.e01`、`.vmdk`、`.vhdx` 和其他可直接仿真的磁盘镜像。
- `clonezilla-to-e01` 适合包含 `disk`、`*-pt.sf`、`*-ptcl-img.*` 的 Clonezilla 备份目录。
