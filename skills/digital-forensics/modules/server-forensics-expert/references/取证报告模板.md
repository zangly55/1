# 取证报告模板

## 1. 任务概述

- 委托事项
- 检材范围
- 分析目标
- 时间范围

## 2. 检材与方法

- 检材类型和来源
- 仿真/转换方式
- 使用的工具和 skill
- 证据保全说明

## 3. 事实发现

- 主机与系统信息
- 账号与登录痕迹
- 服务与进程痕迹
- 网络与远程访问痕迹
- 业务系统痕迹

## 4. 时间线

- 以时间顺序列出关键事件
- 每条记录都保留来源路径或日志名

## 5. 分析结论

- 事实
- 推断
- 待复核事项
- 结论强度

## 6. 限制

- 证据缺口
- 仿真限制
- 未覆盖范围

## 7. 附录

- 关键路径索引
- 日志索引
- 配置索引
- 仿真记录索引
