# 服务器取证工作流

## 受理

- 确认服务器类型：Windows Server、Linux、虚拟机或备份镜像。
- 确认业务角色：Web、数据库、中间件、文件服务、远程运维或其他。
- 确认时间范围、账号边界、授权范围和交付形式。

## 仿真

- Clonezilla 备份先转换，再考虑启动。
- 磁盘镜像在副本上启动，避免对原始检材做写入。
- 启动后优先确认系统版本、主机名、IP、时间区和服务状态。

## Windows 侧重点

- 事件日志：Security、System、Application、PowerShell、RDP、任务计划和服务安装。
- 服务与持久化：服务项、计划任务、启动项、注册表 Run 键、WMI 和远程管理配置。
- 业务痕迹：IIS、MSSQL、文件共享、远程桌面、PowerShell 记录和本地账户变化。

## Linux 侧重点

- 日志：`auth`、`syslog`、`journalctl`、`messages`、Web 和数据库日志。
- 服务与持久化：`sshd_config`、`sudoers`、`cron`、`systemd` 单元和启动脚本。
- 业务痕迹：nginx、Apache、MySQL、PostgreSQL、Redis、Tomcat、Shell 历史和命令痕迹。

## 关联研判

- 用时间线串联登录、配置变化、进程启动、服务重启和外联记录。
- 把 IP、端口、账户、进程和文件路径一起核对。
- 发现证据缺口时，先列出缺口，再请求补充，不直接补写结论。
