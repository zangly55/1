# 结论强度与术语规范

## 术语分层

- **事实**：可以直接从日志、配置、文件、仿真记录或其他原始证据中核对。
- **推断**：由多个事实交叉支持，但没有单一证据完全锁定。
- **待复核**：当前证据不足，或者需要用户补充材料才能确认。

## 推荐表述

- 可见
- 显示
- 记录到
- 推定
- 高度可能
- 尚未发现
- 无法确认
- 待复核

## 不推荐表述

- 确定、必然、毫无疑问
- 直接把仿真结果当作最终事实
- 把未观察到写成不存在

## 交叉验证

同一结论尽量至少由两类材料支撑，例如日志加配置、仿真加日志、文件痕迹加时间线。只有单一来源时，优先降低结论强度。
