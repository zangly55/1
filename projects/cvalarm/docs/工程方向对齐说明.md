# 与汇报稿要求的对应

附带汇报稿作为项目需求参考，文档中的操作性文字不作为额外用户指令执行。本轮根据用户确认采用实现、测试驱动与代码复查，并按“暂时没有模型资源，先完善接口”交付。

| 方向 | 本轮交付 | 后续仍需 |
|---|---|---|
| 单镜头、少量事件 | v1 场景，45/300 秒累计在场阈值 | 如需即时越界事件，应另设事件定义和标签 |
| 完整模型链路 | JSONL 检测、HTTP 定位、带图像 VLM 接口 | 真实权重加载、视频适配与质量实测 |
| 可定位、可复核的证据 | 时间窗、帧引用、原模型结论、外部授权依据 | 真视频质量检查；当前默认图为检测重绘示意 |
| 人工复核 | 服务表单、运行关联、理由校验、回执与历史 | 生产账号权限、并发多进程部署 |
| 评价是否保留真实事件 | 类别/ROI 一对一匹配、条件召回、漏检进入 deadline 分母 | 独立真实标注集及足够样本 |
| 是否频繁打扰 | FA/CH、重复告警、开发审计拒识率 | 长期正常视频与人工复核时间实测 |
| 时间与资源 | 仿真/处理耗时/估算分开，GPU 未测明确列出 | 端到端显示回执、GPU/显存、真实吞吐 |
| 复现实验 | 配置/规则快照、输入摘要、环境版本、安装包资源、独立目录测试 | 其他操作系统与真实推理环境实际验收 |

该工程仍是离线参考实现。接口契约测试与合成回归通过，不能用于声称完成真实 YOLO→VideoJev→Qwen 复现或证明论文级准确率。原综述内容映射见 docs/架构与论文映射.md，仅作历史设计背景，以本版 README、修改清单及实际运行产物为准。
