# 复现指南

## 1. 环境

默认工程需要 Python 3.10+，推荐 Python 3.12。源码运行不需要 pip、torch、CUDA、Node 或网络。本轮实际环境为 Windows、CPython 3.12.14。CI 配置列出 Windows/Linux 与 Python 3.10/3.12/3.13，尚未在远端执行，不能据此宣称各平台均实测。

建议每次复现从新的源码解压目录开始。完整交付包附一个不带第三方依赖的通用 wheel，可在同一 Python 主版本要求下离线安装。安装不会下载模型。

## 2. 源码运行

```bash
cd cvalarm
python run.py demo --profile v1 --out runs/v1 --state-dir state/v1
python run.py test-report --hours 3 --out runs/test --state-dir state/test
python run.py serve --run runs/v1 --state-dir state/v1 --port 8080
python -m unittest discover -s tests -v
```

第一条演示单镜头场景；第二条使用多机位合成数据的默认开发/测试划分，先在开发段标定，再冻结配置并评测。再次运行同一 test-report 会核对冻结清单。调整实际规则、输入、模型或评测配置后，旧冻结会拒绝；明确要建立新基准时使用新 state-dir，或有意使用 --update-freeze。不要为了通过测试降低硬负例数量。

## 3. 安装运行与路径

```bash
python -m venv .venv
# 激活方式见 README，亦可直接使用虚拟环境中的 Python
python -m pip install --no-index --no-deps dist/cvalarm-1.1.0-py3-none-any.whl
python -m cvalarm demo --profile v1 --out runs/v1
```

- 源码运行：配置内部的相对路径、--out、--state-dir、--frames、--cameras、--gt 相对源码根目录。
- 安装运行：上述路径相对当前工作目录；找不到本地 config/... 时使用包内同名内置配置。
- --config 文件的位置相对命令当前目录；文件内的资源路径仍按前述基准解释，不相对该配置文件。
- frames_manifest 内每张图像的相对路径相对 manifest 文件所在目录。
- 迁移工程时保留目录结构即可。规则指针优先根据摘要在当前 state/rules_versions 中查找，兼容原版遗留的绝对路径指针。
- 运行快照会忠实记录用户输入的配置；发布实验前将自行配置的绝对路径换为可共享的相对路径。

## 4. 产物与比较

runs/<name>/ 下保存 run_meta.json、metrics.json、alarms.jsonl、resources.json、models.json、reliability.json、cost.json、report.html 等。state/<name>/ 保存规则、校准和反馈。

比较事件指标、候选、分流和证据内容。run_id、告警 ID、时间戳、卡片签名、墙钟耗时、内存以及硬件/环境信息不同是预期现象；不要求两次目录逐字节相同。使用相同代码、配置、输入和运行模式时，合成场景的确定性事件指标应一致。

输入文件摘要和 Python/可选库版本写入 run_meta.json；模型权重版本需要在 models 或 stage2.scorer 中登记，权重本身应另存 SHA256 与获取来源。密钥只放配置所指向的环境变量，不写入 JSON。

## 5. 构建与检查

构建需要 setuptools>=61；普通运行不需要它。可联网的构建机执行：
```bash
python -m pip wheel . --no-deps -w dist
python tools/check_wheel.py dist/cvalarm-1.1.0-py3-none-any.whl
python tools/check_relocation.py
```

已有构建依赖时可加 --no-build-isolation。wheel 检查使用带空格的临时目录及隔离解释器路径，在另一工作目录生成状态和报告；CI 同样执行该检查。check_relocation.py 会复制两份源码，在中文/空格路径及不同 cwd 下比较关键指标，并迁移冻结状态复跑。

## 6. 未实测部分

可选视频解码依赖通过 pip install ".[video]" 安装；具体 OpenCV、驱动和编解码器版本由运行记录保存。此可选环境未用真实素材验收。YOLO/VideoJev 建议运行在各自适配环境，交换标准 JSONL/HTTP 数据；本包不把特定 CUDA 版本强制加给默认演示环境。

提供真实视频、检测器/时序模型权重或服务后，仍需完成：视频时间对齐、ROI 与授权标注、困难负例标定、独立测试、GPU/显存测量、端到端显示时间测量。服务接口通过不代表模型准确率已通过。
