# 使用说明

当前版本的操作入口为 [README](README.md)，跨机器运行、离线安装与复现实验见 [复现指南](docs/复现指南.md)，真实模型与数据契约见 [适配指南](docs/适配指南.md)。

完整参数可在本机查询：
```bash
python run.py --help
python run.py run --help
python run.py test-report --help
python run.py feedback --help
```

默认运行不需要服务或密钥。显式配置 VLM 后若证据帧缺失或服务不可用，结果转人工并记录失败；不会把规则输出伪装成模型完成了核验。
