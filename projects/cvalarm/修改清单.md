# 本轮修改清单

基于用户提供的原始 ZIP 制作独立优化副本，原 ZIP 与 DOCX 未修改。使用用户批准的实现 → TDD → 代码复查流程；未调用 Kimi。

## 已修改

| 问题 | 修复 | 主要文件 |
|---|---|---|
| 原 state 指针带有旧电脑绝对路径 | 按内容摘要定位当前状态目录，写相对指针 | rules.py |
| wheel 缺配置、离开源码无法启动 | 配置随包构建；安装版状态写工作目录 | setup.py、MANIFEST.in、config.py |
| 模型配置未实际切换定位器 | 接通 scorer 工厂、外部分数、HTTP 视觉评分 | locator.py、visual.py |
| VLM 仅收到文本、模型原结论丢失 | 传入图像与时间戳、保留模型原结果和事实 | verifier.py |
| 模型失败或规则冲突仍可能确证 | 标明失败/冲突，转人工；校验引用帧和时间窗 | verifier.py |
| 缺授权被当作未授权 | 不完整记录判未知；演示授权禁止用于真实回放 | verifier.py、pipeline.py |
| 事件匹配忽略类别/ROI | 同机位、同类别、同 ROI 一对一匹配 | metrics.py |
| 重复告警与假阳性混淆 | 重复告警单列，确证优先匹配 | metrics.py |
| deadline_recall 排除漏检 | 分母包含全部真事件；负时延不计达标 | metrics.py |
| 条件召回口径不一致 | 一对一嵌套路径，只计确证，纠正独立性说明 | reliability.py |
| 测试指标混入开发段 | AUC/时长/候选/调用量限定测试段；审计单列开发口径 | pipeline.py、config.py |
| 无标签被当作负例 | 未标注为未知，相关事件指标为 null | source.py、types.py、pipeline.py |
| 短时演示评价尚未出现的事件 | 只保留输入时轴覆盖的完整合成事件 | source.py |
| 标定跨模型/输入沿用、冻结不核对实际规则 | 绑定内容上下文，核对实际规则/标定/配置 | reproducibility.py、cli.py |
| 失败的定位窗口进入负例标定 | 排除服务异常与无效/低质量窗口 | pipeline.py、cli.py |
| 告警跨运行 ID 重复 | 全局运行 ID + 告警序号；保存完整配置与规则快照 | pipeline.py |
| 旧报告随当前配置漂移 | 报告读取运行快照 | report.py |
| 看板只有反馈 API 没有表单 | 增加结论/理由/备注、回执、历史；轮询保留正在填写内容 | webpage.py、server.py |
| 反馈可关联不存在的告警 | 核对运行与告警，原告警提供元数据，相同提交去重 | server.py、feedback.py |
| 估计资源与时延看起来像实测 | 仿真/处理耗时/费用估算分别标注；未测显存和显示回执明确 | pipeline.py、webpage.py |
| 后置证据超出触发时间 | 限制已到达时间，剩余后文标 pending | evidence.py |
| 文档旧指标、能力描述过满 | 重写入口、复现与适配说明，提供相对路径示例 | README、docs、config |

## 验证与后续

逐项列出的缺失资源、未实现能力、优先级和完成判据见 [项目明细](项目明细.md)。

验证结果及代码复查记录见 docs/验证记录.md。真实模型加载和准确率、GPU/显存/吞吐、现场接流、实际显示时延均未实测。本轮交付接口和可复现参考工程，不包含模型权重或推理服务器。

主要新增回归在 tests/test_optimization.py。部分旧测试依赖错误行为，已同步改为合法事件类别、完整测试授权记录、实际运行告警 ID 和场景绑定标定。没有删减原测试来回避失败。
