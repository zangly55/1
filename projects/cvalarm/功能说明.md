# 功能与边界

| 功能 | 本版状态 | 验证边界 |
|---|---|---|
| 合成流、状态机、跟踪、候选生成 | 可运行 | 标准库回归测试与 CLI 演示 |
| JSONL 检测数据回放 | 可运行 | 文件输入、事件指标、未标注处理 |
| 外部分数 / HTTP 定位 | 接口已实现 | 外部分数文件、本地 HTTP 测试服务；真实模型未测 |
| 图像 VLM 核验 | 接口已实现 | 传输契约、输出校验、冲突处理；真实模型未测 |
| 可追溯证据卡 | 可运行 | 候选、帧索引、时间窗口、模型原结论、签名 |
| 人工复核 | 可运行 | 服务看板表单及 API；跨运行校验与重复提交去重 |
| 规则版本与回滚 | 保留并修复可迁移性 | 内容摘要校验，相对状态路径 |
| 标定与独立测试 | 可运行 | 开发/测试划分、内容绑定、冻结校验 |
| 成本与复核工时 | 估算 | 参数模型，不是财务实测 |
| 合成时延 | 仿真 | 不等同真实设备响应时延 |
| 真实回放处理耗时 | 已记录 | 读取输入到卡片就绪，不含浏览器显示回执 |
| YOLO/VideoJev/Qwen 原生加载 | 未交付模型运行环境 | 无用户素材/权重/服务，需后续实测 |
| 多摄像头接流、生产运维、隐私处理 | 未验收 | 现有配置项不代表已经实现人脸遮挡或自动删除 |

条件召回采用同一批事件的嵌套保留路径，乘积遵循条件概率链式法则，不需要独立性假设。含转人工召回与确证召回单列，转人工不算确证。零正例、缺失标签和零机位小时均不能给出“满分”或“零误报”的结论。

当前内置首版场景是累计在场 45 秒与 300 秒两个阈值场景；尚未增加“刚进入即告警”事件。时序服务必须正确实现事件语义，并针对实际场景重新标定。
