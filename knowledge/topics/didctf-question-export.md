- 日期：2026-11-20（Asia/Shanghai）
- 整理：Codex，依据用户指定站点公开前端代码。
- 来源：https://forensics.didctf.com/practice/questions/practice
- 状态：已核对公开前端调用与本地合成测试；未在登录会话完成端到端导出，不代表真题内容或答案已验证。

## 已观察到的加载方式

公开入口 index-CntTWrQp.js 引用 PracticeQuestions-5MFQkikQ.js 与 practiceCrypto-Ffp0wVYV.js。分类从 GET /api/practice/categories 获取。题目组件调用网站自己的请求封装，向 GET /api/practice/questions 传 category1_id 和 q，预期响应解码后为数组。网站封装负责当前登录会话与题目载荷处理。导出脚本复用该模块，不复制会话材料，不请求答案、提交、考试或评论接口。

## 使用与范围

在已登录站点使用本地油猴脚本，加载分类后选择要读取的分类，顺序读取并下载 Markdown 或 JSON。每分类间隔约 1.2 秒。仅包含题号、题干、题型、分数、选项与分类；附件、案件背景及二级分类描述不在本版范围。原题仅下载到用户本地，不公开发布。脚本通过入口查找当前模块文件名，但模块导出名和响应结构仍可能随网站更新失效。

## 验证与边界

Node 语法检查通过；合成数据测试覆盖去重、空分类、字段白名单、Markdown、部分失败、取消与结构异常。未实测油猴注入及浏览器下载，未确认所有分类的实际访问权限或题目数量。失败结果标记 partial，取消标记 cancelled；complete 仅表示所选分类请求返回预期数组，不能证明整站题库完整。网站自身请求封装仍可能进行一次会话刷新。

只归档方法摘要。原始网页脚本、登录凭据、题目内容与导出文件不随本页上传。
