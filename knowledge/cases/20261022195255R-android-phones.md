## Q11 内部通联账号登录密码（知识库脱敏）

答案：`[登录密码已脱敏，见 answer/Q11.json]`。来源：DeepSeek / P05，GPT 复核（`answer/Q11.json` revision 2）。

1. 对象仍是 `com.socialchat.social_chat_app` 的 `social_chat.db`（SQLCipher，数据库口令与账号登录密码是两套凭据，不能混用）。
2. `user` 表仅一条账号：`id=usr_heiked`、`username=huangzhiyuan`、昵称黄志远，另有 `password_hash`、`password_salt` 与 `config_data`（消息 AES 密钥，脱敏）。
3. 本地决定性复核：该应用使用**双重 SHA-256**，即 `password_hash = SHA256( HEX( SHA256( UTF8(password) + UTF8(password_salt) ) ) )`；对候选口令计算后与库中 64 位十六进制值逐字节一致，`MATCH=True`。
4. 先前单层 SHA-256 的 8 位数字全空间未命中，改为双重 SHA-256 后命中；说明不能只试一种散列规则就下“无明文/密码不可解”的结论。
5. 外部题解的同一值仅作交叉线索，最终以本地 `password_hash` 复算为准；答案保留前导 0 与 8 位长度。

知识库不记录明文密码、盐、散列值或 SQLCipher 口令；这些原值只在 `answer/Q11.json` 与案件答案中保留。
