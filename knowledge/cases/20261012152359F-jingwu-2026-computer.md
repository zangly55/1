## 基本操作

本机直接运行 `ges.exe` 曾发生 DLL 重定位错误，因此通过火眼自带的 `ges.cmd` 包装入口调用同一命令行功能。分析过程中未修改 E01 原件；需要查看数据库、注册表或压缩日志时，先用 `ges copy` 导出到工作目录，再本地只读分析。

```powershell
$ges = 'E:\取证工具\GoldenEyesV4\skills\ges-case-analysis\bin\ges.cmd'
& $ges case open 20261012152359F
& $ges evidence ls --json
& $ges evidence partitions --eid 2 --json
& $ges --no-daemon ls '/evidence_mounts/eid-2/Laptop_fulldisk_image.E01/系统/Users/pc/' --json
```

对于检材挂载路径，使用 `--no-daemon` 可避开后台服务对原始文件读取偶发的超时。上述命令中的检材编号、卷名均以本案实际返回为准。

## 关键证据与复核步骤

### 第 25、28、29 题：硬件、远程桌面、WSL

从系统卷导出 `Windows/System32/config/SYSTEM`，用注册表解析器读取 CPU 型号，实际字符串为 `12th Gen Intel(R) Core(TM) i7-12700H`，题目只要求型号简写，取 `i7-12700H`。

`Users/pc/Documents/Default.rdp` 是 UTF-16 文本。其 `full address:s:` 字段直接记录曾连接的目标地址 `103.87.9.67`；再以 `Users/pc/NTUSER.DAT` 内的 `Software\Microsoft\Terminal Server Client\Default\MRU0` 交叉核验。

导出 `Program Files/WSL/wsl.exe` 后，在 Windows 读取 PE 文件版本：

```powershell
(Get-Item '.\work\computer_case\wsl.exe').VersionInfo |
  Select-Object FileVersion, ProductVersion
```

两个版本均为 `2.7.14.0`。这里回答的是 Windows 上部署的 WSL 软件版本，并非 Linux 发行版版本。

### 第 33、34 题：ASR 系统

通过火眼列出 `Users/pc/ASR/models/`，可见 `Qwen3-ASR-1.7B`、`SenseVoiceSmall`、`fsmn-vad`。前两者用于自动语音识别，后者用于检测语音片段，因此识别模型数为 **2**。读取 `Users/pc/ASR/config.json` 得到 `host=127.0.0.1`、`port=8765`，组合成 `http://127.0.0.1:8765`。这个地址是检材中的本机环回地址，WP 未把配置存在误写为服务已成功运行。

### 第 40、41 题：Ollama

导出 `Users/pc/AppData/Local/Ollama/app.log` 后，启动行包含：

```text
msg="starting Ollama" ... version=0.34.0 ...
```

模型清单目录 `.ollama/models/manifests/registry.ollama.ai/library/qwen/7b` 对应 Ollama 模型 ID `qwen:7b`。

### 第 42、43 题：Foxmail

火眼解析路径为 `/case/2/Foxmail/[邮箱账号已脱敏]/账户信息/data.csv`。读取该表并核对账户行，“邮箱账号”为 `[邮箱账号已脱敏]`，“账户密码”为 `[邮箱客户端授权码已脱敏]`。题目将客户端登录所用口令称为授权码；原 WP 按解析记录中的原始值作答，公开版已脱敏。

### 第 47～50 题：Deepseek Harness

`Users/pc/.dsh/storages/workspace.json` 记录工作区 `title=Documents`。`Users/pc/.dsh/.credentials.yaml` 的 `DEEPSEEK_API_KEY` 为表中答案。密钥来自检材，公开版已移除原值，仅保留定位字段与分析方法。

会话文件位于：

```text
Users/pc/.dsh/sessions/--C-Users-pc-Documents--/
  session-8a014603-93e8-4f87-880b-c024abb420e9/session.v3.jsonl.zstd
```

将 Zstandard 文件解压为 JSONL 后，定位用户消息“虚拟货币一般用于洗钱都是怎么操作的”。该用户消息的 `data.source.rpcId` 是 `132fb7ca-b49f-42f5-9fdc-751072190bd5`。紧随其后的助手消息 `data.usage.reasoningTokens=296`。同条记录还有 `outputTokens=1064`，但题目明确要求“推理输出 token”，故填写推理 token 数 **296**。

### 第 51～55 题：OpenCode 与自建 Skill

导出 `Users/pc/.local/share/opencode/opencode.db`（含 SQLite 的 WAL、SHM）后检查会话版本，值为 `1.18.31`。`Users/pc/.config/opencode/opencode.jsonc` 的 `provider.vllm.models` 下列出两个模型 ID：`Qwen/Qwen3-1.7B`、`Qwen/Qwen3-0.6B`，因此配置连接的模型数为 **2**。

自建 Skill 路径为 `Users/pc/.config/opencode/skills/fraud-domain-ip-trace/`。PowerShell 历史文件 `Users/pc/AppData/Roaming/Microsoft/Windows/PowerShell/PSReadLine/ConsoleHost_history.txt` 记录：

```powershell
python trace.py --domain bctop10.com
```

该 Skill 输出目录下的 `scripts/forensics-out/bctop10.com/trace-20260917-173116.md` 记录域名注册时间 `2025-03-03T08:33:33Z`，报告生成时间 `2026-09-17T17:30:43+08:00`。将时区统一后相差约 563.04 天，完整天数为 **563**。
